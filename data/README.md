# Данные модели симптомов

Модель обучается на англоязычных обращениях владельцев автомобилей, полученных NHTSA в 2020–2024 годах. Целевая переменная берётся из поля `COMPDESC`, текст из `CDESCR`, обращение идентифицируется по `ODINO`. Категории описывают компонент, указанный в жалобе. Причину неисправности подтверждает диагностика конкретного автомобиля. [Наборы данных NHTSA](https://www.nhtsa.gov/nhtsa-datasets-and-apis#complaints) · [Описание полей](https://static.nhtsa.gov/odi/ffdd/cmpl/CMPL.txt)

При подготовке исключаются обращения с несколькими группами компонентов, неподдерживаемые категории, короткие тексты и дубликаты нормализованных описаний. В обучающую, проверочную и тестовую выборки попадают разные сочетания марки и модели. Выборки ограничены по объёму каждой категории. Метрики поэтому характеризуют этот набор категорий и способ отбора. Для прогноза модель использует только описание симптомов. Русский ввод преобразуется небольшим словарём автомобильных выражений. Оценка качества относится к английским жалобам.

`model_metrics.json` содержит размеры выборок, accuracy, macro F1, top-3 accuracy, частоту наиболее распространённой тестовой категории, матрицу ошибок и результаты проверки Logistic Regression и Random Forest на одной валидационной выборке. Порядок строк и столбцов матрицы задан массивом `classes`. `symptom_model.json.gz` содержит признаки TF-IDF и коэффициенты обученной логистической регрессии. Оба файла входят в проект. Для выполнения классификации достаточно стандартной библиотеки Python.

## Переобучение

Запустите команды из папки проекта с Python 3.11 или 3.12.

```powershell
python -m pip install scikit-learn==1.7.2
python train_diagnosis.py --archive nhtsa-2020-2024.zip
```

Если архив отсутствует, скрипт загрузит его с NHTSA. Версия файла может меняться после обновлений NHTSA. Чтобы сверить архив с исходным обучением, сравните SHA-256 с `archive_sha256` в `model_metrics.json`.
