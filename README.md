# AI Car Doctor

Учебный веб-проект по машинному обучению на Python. Приложение классифицирует автомобильные симптомы, расшифровывает распространённые коды OBD-II и отображает измерения по звуку, расходу топлива и журналам поездок.

## Запуск на Windows x64

1. Распакуйте весь ZIP в папку, доступную для записи.
2. Откройте **start.cmd**. Сайт откроется в браузере. Локальный адрес также появится в консоли.
3. Оставьте окно консоли открытым на время работы. Чтобы остановить приложение, нажмите **Ctrl+C** в этом окне.

В архив входит Python 3.12, Flask и NumPy. После распаковки интернет для демонстрации не требуется. История сохраняется в `instance/history.sqlite3` рядом с исходниками.

Из исходников на другом компьютере с Python 3.11 или 3.12 можно запустить проект так.

    python -m pip install -r requirements.txt
    python app.py --open

## Сценарий защиты

1. Во вкладке **Симптомы** нажмите **Заполнить пример**, затем **Начать диагностику**. Haval M6 2024 с описанием стука при запуске и повышенного расхода получает список категорий, близких к обращению. На первом месте будет «Двигатель и охлаждение». Баллы показывают выход классификатора по категориям жалоб.
2. Во вкладке **OBD-II коды** введите `P0301`. Справочник объяснит, что код сообщает о пропусках воспламенения в первом цилиндре, и покажет вопросы для проверки.
3. Скачайте WAV из вкладки **Звук** и загрузите его обратно. Этот файл содержит искусственно созданный сигнал. Анализ покажет форму сигнала и частотный пик около 86 Гц.
4. Во вкладке **Расход топлива** сравните `10,8` и `8,7` л/100 км. Приложение покажет рост примерно на 24,1% относительно указанного обычного расхода.
5. Во вкладке **Телеметрия** скачайте и загрузите демонстрационный CSV. Он содержит десять искусственных замеров. Затем откройте **Прогноз** и используйте последний импорт. Оценка при сохранении тренда составит около 82 °C через 30 секунд.
6. Во вкладке **AI-ассистент** выберите вопрос про P0301. Откройте **Историю**, затем **О модели**, чтобы показать сохранённые проверки и результаты оценки классификатора.

## Данные и результаты модели

На вход модели поступает описание симптомов. Марка, модель, год и двигатель сохраняются в карточке проверки. Конвейер обучения использует TF-IDF и сравнивает Logistic Regression с Random Forest. На валидации их macro-F1 составили соответственно 0,8653 и 0,8322, поэтому в приложение вошла логистическая регрессия.

Данные взяты из реальных англоязычных обращений NHTSA за 2020–2024 годы. У каждой записи класс соответствует системе автомобиля, указанной в жалобе. После очистки и отбора в обучении было 19 600 обращений, в валидации 4 900, в тесте 6 238. Сочетания марки и модели распределены по разным выборкам. На тесте accuracy составила **87,02%**, macro-F1 — **0,871**, top-3 accuracy — **96,97%**. Отдельная оценка русского словаря и применимости к Haval не проводилась. [Набор данных NHTSA](https://www.nhtsa.gov/nhtsa-datasets-and-apis#complaints)

Чтобы воспроизвести обучение, воспользуйтесь `train_diagnosis.py` и инструкциями в `data/README.md`. Архив NHTSA загружается при переобучении. Файл обученной модели и полный отчёт метрик уже входят в проект.

## Как устроены модули

| Модуль | Что делает |
| --- | --- |
| Симптомы | Ранжирует семь категорий компонентов по тексту и запрашивает уточнение при недостатке признаков. |
| OBD-II | Объясняет 17 распространённых кодов по справочнику с указанием источников. |
| Звук | Читает PCM WAV от 0,5 до 30 секунд, измеряет амплитуду и частотный спектр. Для классификации неисправностей по звуку понадобятся размеченные записи двигателей. |
| Расход | Сравнивает замер с заданной нормой или недавними замерами. Сопоставляйте поездки в похожих условиях. |
| Телеметрия | Читает `timestamp,rpm,coolant_c,speed_kmh` из CSV и показывает последние измерения и график температуры. `timestamp` принимает время ISO 8601. |
| Прогноз | Строит локальный линейный тренд температуры по журналу. R² описывает соответствие линии имеющимся замерам. Прогнозирование поломок потребует истории с подтверждёнными отказами. |
| Ассистент | Подбирает объяснение по коду или ключевым словам из локального справочника. |

Интерфейс отправляет данные в Flask API. Модули рассчитывают результат, Flask сохраняет его в SQLite и возвращает браузеру. Исходные WAV-файлы после анализа не сохраняются. Собранные ряды телеметрии сохраняются для повторного анализа.

### Подключение адаптера

Для записи через ELM327 с последовательным портом установите `obd` в обычную среду Python и запустите сборщик на стоящем автомобиле. Замените `COM3` своим портом. Сборщик читает обороты, температуру и скорость и записывает их в CSV. Проверка выполнена с имитацией адаптера.

    python -m pip install obd
    python obd_record.py --port COM3 --duration 60 --output trip.csv

### Проверки

Запуск автоматических проверок из распакованной папки.

    runtime\python.exe -B -m unittest discover -s tests
